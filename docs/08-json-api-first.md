# JSON:API First

## Response content type

API Gateway responses generated by `JsonApiResponseFactory` use:

```text
Content-Type: application/vnd.api+json
```

## Success response

Current price list response:

```json
{
  "data": {
    "type": "price-lists",
    "id": "default",
    "attributes": {
      "products": [
        {
          "id": "P-001",
          "name": "Café Especial 500g",
          "price": 12.9,
          "currency": "USD"
        }
      ]
    }
  }
}
```

## Error response

```json
{
  "errors": [
    {
      "status": "400",
      "title": "Bad Request",
      "detail": "Path parameter 'priceListId' is required"
    }
  ]
}
```

## Current simplification

For the MVP, products are returned inside `attributes.products` of the price list.

Later, if the API needs stricter JSON:API modeling, products can be returned as relationships plus `included` resources.
